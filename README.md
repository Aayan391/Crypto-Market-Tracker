# 🚀 Crypto Market Tracker

**Track. Explore. Save.**

Crypto Market Tracker is a responsive cryptocurrency tracking website that allows users to explore cryptocurrency markets, monitor live prices, view detailed coin information, and manage their favorite cryptocurrencies through a personalized watchlist.

## ✨ Features

- **Live Cryptocurrency Data** – Fetch real-time cryptocurrency market data using the CoinGecko API.
- **Top 20 Cryptocurrencies** – Explore the top 20 cryptocurrencies by market capitalization.
- **Search & Sort** – Search cryptocurrencies and sort them by price, market cap, percentage change, and name.
- **Coin Details Page** – View detailed information about individual cryptocurrencies.
- **Interactive Price Charts** – Analyze historical price movements using interactive charts.
- **Watchlist Management** – Add and remove favorite cryptocurrencies from your personal watchlist.
- **Dark & Light Mode** – Switch between dark and light themes.
- **Responsive Design** – Optimized for desktop, tablet, and mobile devices.

## 🔌 API Used

This project uses the **CoinGecko API** to retrieve cryptocurrency market data, coin details, and historical price information.



## ⚙️ Getting Started

Follow these steps to run the project locally:

**1. Clone the repository**
https://github.com/Aayan391/Crypto-Market-Tracker

**2. Open the project**

Open the project folder in VS Code.

**4. Run the project**

Use the Live Server extension in VS Code to launch `index.html` in your browser.

## 💾 Data Storage

The project uses browser LocalStorage to save users' watchlist selections. Saved cryptocurrencies remain available even after refreshing the page.

## 📱 Responsive Design

The website is designed to provide a smooth experience across different screen sizes, including desktops, tablets, and mobile devices.
